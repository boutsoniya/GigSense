# Past-event data

`past_events_template.csv` is the column layout for the 5-10 past events I plan to collect from organisers.

- Collect only with the organiser's permission, and only what's needed (amounts and turnout, not personal details).
- Anonymise event names if asked.
- Keep real data out of the public repo: put it in `data/private/` or name files `*.private.csv` (both are git-ignored), and publish only aggregated, permissioned findings.

No real event data is included in this repository yet.
